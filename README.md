# Vignesh J — Executive 3D Motion Portfolio

A bespoke, high-performance executive digital portfolio for **Vignesh J**, bridging **BA Economics & MBA Business Strategy** with **Hands-on Operations Leadership (Food Industry Management, Sales & Cashiering)**.

Designed with **Executive Brutalism & Kinetic Precision** — deliberately eliminating glassmorphism and generic cookie-cutter templates in favor of solid architectural surfaces, warm burnished brass accents, and GPU-accelerated 3D motion.

---

## Key Features

- **Interactive 3D Kinetic Core**: Built with Three.js WebGL featuring procedural metallic materials, triple concentric gimbal coordinate rings, satellite nodes, cursor-following inertia, drag-to-orbit controls, and click-pulse dynamics.
- **Operations & Unit Economics Simulator**: Real-time interactive model evaluating daily covers, average ticket sizes, COGS %, and prevented inventory shrinkage savings.
- **Zero Glassmorphism Policy**: Solid, opaque, tactile surfaces with 1px architectural hairline borders and physics-based 3D card tilt with specular light highlights.
- **Synthesized Audio Feedback**: Mechanical tactile click feedback powered by the Web Audio API.
- **Direct Dossier**: Contact links, one-click clipboard copy actions, and mobile-responsive layouts.

---

## Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES Modules)
- **Styling**: Vanilla CSS (Custom Design System, Zero Tailwind, Zero Glassmorphism)
- **3D Graphics**: Three.js (WebGL)
- **Tooling & Motion**: Vite, Lucide Icons, Motion MCP

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation & Local Run

```bash
# Clone the repository
git clone https://github.com/vickyrock826/vicky-j.git

# Navigate into directory
cd vicky-j

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build

```bash
npm run build
```

The output will be bundled in the `dist/` directory.
